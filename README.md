# 个人作品集网站

一个现代化、响应式的个人作品集网站，使用Vue 3构建，支持背景透明度调整、分级标签系统和作品管理功能。

## 功能特点

### 1. 背景透明度调整
- 为所有模块（主页、关于我、技能、作品、联系我）添加了独立的背景透明度调整滑块
- 支持上传图片/视频作为背景，并实时调整透明度
- 使用CSS线性渐变实现了平滑的透明度效果

### 2. 分级标签系统
- 为每个作品添加了标签功能
- 自动提取所有唯一标签并显示在筛选栏中
- 点击标签可快速筛选对应作品，包含"全部"选项

### 3. 作品管理
- 支持添加、编辑、删除作品
- 每个作品可上传多张图片
- 作品详情模态框展示

### 4. 个人技能管理
- 支持添加、编辑、删除技能
- 可设置技能名称、熟练程度和图标

### 5. 个性化设置
- 主页标题、副标题、按钮文字可编辑
- 个人信息（姓名、职位、简介等）可自定义
- 支持上传个人头像

## 技术栈

- Vue 3
- HTML5
- CSS3
- JavaScript

## 如何运行

### 方法1：直接打开

1. 双击 `index.html` 文件在浏览器中打开

### 方法2：使用本地服务器

```bash
# 使用Python 3
python -m http.server 8000

# 或使用Python 2
python -m SimpleHTTPServer 8000
```

然后在浏览器中访问 `http://localhost:8000`
